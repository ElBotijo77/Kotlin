## Procedimiento

- Todo el contenido que se suba a `main` estará finalizado, evitando así código incompleto.
- Cada rama contendrá un único ejercicio o tarea, con un nombre descriptivo siguiendo el formato `tipo/descripcion`, por ejemplo:
  - `ejercicio/kotlin-colecciones`
  - `proyecto/app-lista-tareas`
- Al terminar el trabajo, la rama se fusiona en `main` y se elimina.
- Todos los commits seguirán el formato [Conventional Commits](https://www.conventionalcommits.org/es/).
